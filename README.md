# Licences

Canonical texts of the licences under which MBSE Consulting supplies its software.

Artifacts we ship carry a copy of the applicable licence. This repository holds the authoritative
version of each, at a stable URL, so that a licence identifier recorded in a bill of materials
resolves to the text that applied at the time of delivery.

## Current

| Licence | Identifier | Text |
|---|---|---|
| MBSE Consulting Software Licence 1.0 | `LicenseRef-mbseconsulting-software-1.0` | [software/1.0.txt](https://licenses.mbseconsulting.com/software/1.0.txt) |

The identifier follows the SPDX convention for licences that do not appear on the SPDX Licence List.
Tools that encounter it should fetch the text at the URL above.

## Immutability

A published version never changes. Corrections and revisions are issued as a new version at a new
path, and earlier paths continue to resolve. A recipient auditing a delivery from an earlier year
retrieves the text that governed that delivery, not a later one.

## Scope

These licences govern the products and deliverables that MBSE Consulting supplies to its clients.
They are proprietary licences, not open source licences: they restrict redistribution and reserve
fields of use. Some MBSE Consulting software is released under the Apache Licence 2.0 instead; those
artifacts carry that licence in their own repositories.
