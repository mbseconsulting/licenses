# Published licences

Every version MBSE Consulting has published, newest first. A row never changes once it appears, and
a row is never removed, because delivered material refers to the URL it names.

| Licence | Version | Dated | Identifier | URL |
|---|---|---|---|---|
| MBSE Consulting Software Licence | 1.0 | August 2026 | `LicenseRef-mbseconsulting-software-1.0` | https://licenses.mbseconsulting.com/software/1.0.txt |

## Identifier

The identifier follows the SPDX convention for a licence absent from the SPDX Licence List. The
`LicenseRef-` prefix marks it as such, and tools that validate against the list accept the prefixed
form.

## Files per version

Each version ships two files, both served at the path they occupy.

| File | Contents |
|---|---|
| `software/<version>.txt` | The licence text. Authoritative. |
| `software/<version>-header.txt` | The file header notice, reproducing the appendix of that text. |

## Text conventions

| Property | Value |
|---|---|
| Line width | 79 columns maximum |
| Body indent | 3 spaces |
| Banner centre | column 35 |
| Character set | ASCII |
| Final byte | newline |

The published page reproduces the whitespace, so reflowing a paragraph changes what a recipient
reads.
